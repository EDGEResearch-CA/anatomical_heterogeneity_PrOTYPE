# Cancers 2026, 18, 2115: PrOTYPE and Anatomiccal Site Heterogeneity Analysis
This repository contains the R code used for the analysis associated with the manuscript on Nanostring-based heterogeneity in the study cohort.

## Overview
This repository includes the script used to process normalized PrOTYPE expression data, perform the main statistical analyses,
and generate the figures and tables included in the manuscript.
The code provided here represents the public-facing version of the analysis pipeline and includes only the components needed to generate the published results.

## Contents
- `paper_code.R` — main analysis script.

## Analysis performed
The analysis in this repository includes:
- data grouping and preprocessing,
- statistical testing,
- generation of manuscript figures and tables.

## Requirements
- R version: 4.5.1

## Data availability
This public repository contains the code needed for the published analysis, but not any restricted or unpublished data.
The normalized expression data can be found in the supplementarty files of the manuscript. The PrOTYPE predication where established using the PrOTYPE webtool, as published.

## Notes
- This public version excludes exploratory analysis and any code related to unpublished work.
- File paths may need to be updated depending on your local setup.
- The script was simplified for public release to improve readability and reproducibility.
